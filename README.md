# C++ OOP & Data Structures — Projects

Eight hands-on **C++ projects** that apply object-oriented programming and data structures. These exercises are part of my **Algorithms & Problem Solving — Level 4** practice.

## Projects

| # | Project | Focus |
|---|---|---|
| 1 | [Doubly Linked List](project%20-%201%20%28%20doubly-linked-list%20%29) | Linked-list implementation |
| 2 | [Queue](project%20-%202%20%28%20queue%20%29) | Queue built on linked-list classes |
| 3 | [Stack](project%20-%203%20%28%20stack%20%29) | Stack built on reusable structures |
| 4 | [Dynamic Array](project%20-%204%20%28%20Dynamic%20Array%20%29) | Dynamic-array class |
| 5 | [Queue Array](project%20-%205%20%28%20Queue%20array%20%29) | Array-based queue |
| 6 | [Stack Array](project%20-%206%20%28%20stack%20array%29) | Array-based stack |
| 7 | [Undo & Redo](project%20-%207%20%28%20undo%20%26%20redo%20%29) | Undo/redo operations |
| 8 | [Queue Line](project%20-%208%20%28%20Queue%20Line%20%29) | Queue/line ticketing exercise |

## Structure

Each project is in a separate folder containing a `main.cpp` file and any required headers or `DS/` classes.

## How to Run

Open the desired project's `main.cpp` in your C++ development environment, keeping its related header files available for compilation.

## Purpose

Practice **reusable classes, data structure implementations, and problem solving** through independent, progressively more involved exercises.
